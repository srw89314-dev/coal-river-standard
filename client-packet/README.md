## Using the packet

Start with the owner guide. Copy the relevant templates into one private project and replace placeholders. Use one project reference and dated versions throughout. Send only the relevant client pages; preserve accepted versions and approval evidence. The editable Word edition is the owner-facing packet; these Markdown files are the maintained source. Update both together when terms change.

Package prices are the approved build prices, not monthly care subscriptions. Support, refunds, ownership/license terms, taxes and any recurring services must be resolved before a real agreement or invoice is issued.
