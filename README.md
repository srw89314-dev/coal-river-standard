# Coal River Standard

Revenue-focused launch site and sales materials for a local-business web design service.

## Before public launch

1. Set `CONTACT_EMAIL` in `dist/app.js` to the inbox that should receive leads.
2. Confirm the founding-client price and included scope.
3. Replace the illustrative preview with the first approved client example when available.
4. Add the purchased domain only after it is registered in the owner's name.

The site intentionally contains no invented testimonials, customer counts, awards, or portfolio claims.
